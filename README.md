# LoopNote - リアルタイム問題演習アプリ

Google Sheetsにある問題・回答・解説を読み込み、手動更新で演習画面へ反映するWebアプリです。外部パッケージは不要です。

## PCをサーバーにしない公開方法

このフォルダはVercelへそのまま公開できる構成です。Vercelへデプロイすると、発行されたHTTPS URLをPC・スマホから利用でき、PCを起動しておく必要はありません。`api/questions.js` がクラウド上でスプレッドシート同期を行います。

1. このフォルダをGitHubリポジトリへ登録します。
2. Vercelで「Add New Project」を選び、そのGitHubリポジトリを読み込みます。
3. Framework Presetは「Other」のまま、Deployを実行します。
4. 発行された `https://...vercel.app` をスマホで開きます。

## 起動

いちばん簡単な方法は、`start-loopnote.bat` をダブルクリックすることです。サーバーとブラウザが自動で開きます。

WindowsではPowerShellだけで起動できます。

```powershell
.\server.ps1
```

Node.js 18以降がある場合は、次のコマンドでも起動できます。

```bash
npm start
```

ブラウザで `http://localhost:4173` を開いてください。初期状態は問題なしで、設定画面からGoogle Sheetsを接続します。

## Google Sheetsとの接続

1. 1行目に次の7列を左から順番に作ります。1行が1問です。

   `問題番号, 科目, 単元, テーマ, 問題文, 回答, 解説`

   この7列形式は自動的にトップの `過去問` に分類されます。科目には `労働基準法` など、単元には章や分野、テーマには個別論点を入力します。単元・テーマが空欄なら、それぞれ `標準単元`・`標準テーマ` として扱います。回答が `○` または `×` なら○×形式で自動採点、数字なら数字入力形式で自動採点、それ以外の文字なら「答えを見る」形式の自己採点になります。回答が空欄の行は正解未登録として表示されます。

   アプリのトップには科目が並び、科目、単元の順に選び、最後に複数のテーマをまとめて選択して演習できます。従来の `問題番号, 学習, 科目, 種類, 問題文, 回答, 解説` 形式と `問題番号, 科目, 論点, 問題文, 回答, 解説` 形式も移行用として読み込めます。

2. Google Sheetsの共有設定を「リンクを知っている全員が閲覧可」にします。
3. 現在の本番アプリは新しい「社労士アプリ」シートへ自動接続します。別のシートを使う場合は、右上の「設定」で通常の編集URLを貼り付けます。
4. 「接続して保存」を押します。以後は右上の更新ボタンで手動同期できます。

○または×を選択すると、その肢を即時採点して解説を表示します。Apps ScriptのWebアプリURLを指定する場合は、配列または `{ "questions": [...] }` のJSONを返す形式にも対応しています。

回答後の解説欄では、問題ごとに付箋を登録・編集・削除できます。保存した付箋は、次回その問題へ回答した直後に解説と一緒に表示されます。付箋は端末のブラウザ内に保存され、記憶リセットでは削除されません。

ホームの「前回の誤答」と「期間指定復習」では、`学習` と `科目` を組み合わせて復習範囲を指定できます。例えば `模試・問題集` と `労働基準法` を選ぶと、その組み合わせの誤答だけを復習します。

リザルト画面では、その周で不正解だった問題だけをすぐに解き直せます。この解き直し結果は通常の回答履歴や学習済み件数へ重複記録しません。

## 問題データのキャッシュ

取得した問題は、正規化後にブラウザのIndexedDBへ保存されます。2回目以降の起動では保存済み問題を先に表示するため、通常の再読み込みを待たずに演習を開始できます。

- 初回アクセス、接続先変更時: 全問題を取得してIndexedDBへ保存
- 通常の再読み込み: IndexedDBから即時復元
- 右上の更新ボタン: Vercelとブラウザのキャッシュを使わず強制同期
- スプレッドシート更新時: 右上の更新ボタンで手動同期

IndexedDBは端末・ブラウザごとの保存です。サイトデータを削除すると問題キャッシュも削除されますが、次回アクセス時にスプレッドシートから再作成されます。回答履歴と途中セッションは従来どおりlocalStorageへ保存します。

## 環境変数で接続先を固定

画面設定を使わず、起動時の既定値として指定することもできます。

```powershell
$env:SHEET_CSV_URL="https://docs.google.com/spreadsheets/d/.../edit#gid=0"
npm start
```

ポートは `PORT` 環境変数で変更できます。
